Анализ текста на тезисы

Вставьте произвольный текст (статью, обсуждение, пост) — LLM выделит из текста набор тезисов (вопрос + ответ). Выберите тему для сохранения или оставьте «Авто» — тогда LLM сам определит темы и попытается привязать их к уже существующим в базе.

Режим «Авто»: LLM определит темы в тексте, сгруппирует тезисы по темам и попытается привязать к существующим. Требуется дополнительный API-запрос для группировки.
