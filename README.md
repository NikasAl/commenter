# Commenter

Chrome-расширение для формирования аргументированных ответов на комментарии и посты с помощью LLM.

Идея проста: вы заранее собираете **тезисы** по темам (в формате «Вопрос → Ответ»), а когда нужно ответить на комментарий — выбираете тему, и LLM формирует ответ на основе ваших тезисов.

## Возможности

- **Темы и тезисы** — создавайте неограниченное количество тем, в каждой храните тезисы в формате «Вопрос — Ответ»
- **Генерация ответа** — выберите тему, вставьте текст для ответа, получите ответ с учётом ваших тезисов
- **Работа с VK** — извлечение контекста поста и комментариев прямо со страницы VK, генерация ответа и вставка в поле ввода
- **Создание тезисов на лету** — скопировали интересный текст на странице, нажали хоткей — сохранили как тезис в пару кликов
- **Редактор промпта** — настраивайте системный промпт для генерации прямо в интерфейсе, без редактирования кода
- **Импорт/Экспорт** — импортируйте тезисы из текстового файла (T/Q/A формат) с дедупликацией, экспортируйте обратно
- **LLM-провайдеры** — поддержка **Z-AI** (GLM-4) и **OpenRouter** (GPT-4o, Claude, Gemini, DeepSeek, Llama и другие)
- **Анализ текста** — вставьте статью или обсуждение, LLM автоматически выделит из текста тезисы в формате «Вопрос — Ответ» с привязкой к темам
- **Копирование в один клик** — сгенерированный ответ копируется в буфер обмена мгновенно
- **Повторная генерация** — не устраивает вариант? Нажмите «Ещё вариант»
- **Всё хранится локально** — API-ключи, темы и тезисы сохраняются только в вашем браузере

## Установка

### Из исходников (режим разработчика)

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/NikasAl/commenter.git
   ```
2. Откройте в Chrome `chrome://extensions/`
3. Включите **«Режим разработчика»** (переключатель в правом верхнем углу)
4. Нажмите **«Загрузить распакованное расширение»**
5. Выберите папку `commenter`

## Как пользоваться

### Вариант 1: Отдельная страница управления

Основной интерфейс расширения открывается на **отдельной вкладке браузера** и не закрывается при потере фокуса. Открыть его можно:

- Кликнув по иконке расширения → **«Полная версия»**
- Через `chrome://extensions/` → Commenter → «Подробности» → «Параметры расширения»

На странице 5 вкладок:

#### 1. Генерация

1. Выберите тему из выпадающего списка
2. Вставьте текст комментария или поста, на который нужно ответить
3. Нажмите **«Сформировать ответ»**
4. Скопируйте результат или запросите другой вариант

Кнопка **«Копировать промпт»** позволяет скопировать собранный промпт (системный + контекст) для ручного использования в любом чате с LLM.

#### 2. Темы

- **Добавить тему** — создайте тему с тезисами вручную
- **Импорт** — вставьте текст в формате T/Q/A для массового добавления тем и тезисов (дубликаты автоматически пропускаются)
- **Экспорт** — скачайте все темы и тезисы в текстовый файл

Формат импорта/экспорта:
```
T:Название темы
Q:Текст вопроса
A:Текст ответа

Q:Следующий вопрос
A:Следующий ответ

T:Другая тема
Q:...
A:...
```

#### 3. Промпт

Редактор системного промпта, который отправляется LLM вместе с тезисами. Поддерживаются шаблонные переменные:

- `{{topic}}` — подставляется название выбранной темы
- `{{theses}}` — подставляются все тезисы темы в формате «[Тезис N] Вопрос / Ответ»

Есть предпросмотр, кнопка сброса к значению по умолчанию и сохранение без перезагрузки расширения.

#### 4. Анализ текста

Вкладка для автоматического извлечения тезисов из произвольного текста — статей, постов, обсуждений, новостных материалов и т.д. LLM анализирует текст и выделяет ключевые тезисы в формате «Вопрос — Ответ», готовые для сохранения в базу.

Поддерживается два режима:

- **С выбранной темой** — выберите существующую тему из списка, вставьте текст, нажмите **«Анализировать текст»**. LLM выделит тезисы по заданной теме. После анализа можно отметить нужные тезисы чекбоксами и добавить их в базу одной кнопкой.

- **Авто (определение тем)** — оставьте выбор темы в положении «Авто». LLM самостоятельно определит темы, затронутые в тексте, и распределит тезисы по ним. Затем запустится **шаг группировки**: LLM попытается привязать найденные темы к уже существующим в вашей базе. Вы сможете:
  - Увидеть, какие темы привязаны к существующим, а какие новые
  - Сменить привязку вручную через выпадающий список
  - Повторить группировку, если результат не устроил
  - Сохранить выбранные тезисы в базу (новые темы создадутся автоматически)

#### 5. Настройки

- Выбор провайдера (**Z-AI** или **OpenRouter**)
- Вставка API-ключа
- Выбор модели из списка или ручной ввод

### Вариант 2: Интеграция с VK (хоткеи на странице)

При открытии страницы **vk.com** расширение автоматически активирует контент-скрипт, который добавляет три горячие клавиши. Для работы нужен настроенный API-ключ (вкладка «Настройки»).

#### Хоткеи

| Горячая клавиша | Действие |
|---|---|
| `Ctrl+Shift+P` | Извлечь контекст поста + комментарии, собрать промпт |
| `Ctrl+Shift+G` | Отправить промпт в LLM, вставить результат в поле комментария |
| `Ctrl+Shift+L` | Открыть форму создания нового тезиса (из буфера обмена) |

#### Сбор промпта (`Ctrl+Shift+P`)

1. На странице VK поставьте фокус в **поле комментария** (кликните в поле ввода под постом)
2. Нажмите `Ctrl+Shift+P`
3. Появится **плавающая панель** с собранным контекстом:
   - Автор поста и текст поста
   - Список комментариев (автор + текст)
   - Контекст ответа (если отвечаете на конкретный комментарий)
   - Системный промпт с тезисами выбранной темы
4. В панели есть **селектор темы** — выберите нужную тему, и промпт мгновенно пересоберётся с её тезисами
5. Промпт автоматически копируется в буфер обмена

#### Генерация и вставка (`Ctrl+Shift+G`)

1. Убедитесь, что промпт собран (`Ctrl+Shift+P`) и тема выбрана
2. Фокус должен быть в поле комментария VK
3. Нажмите `Ctrl+Shift+G`
4. Панель покажет статус «Генерация...», затем результат LLM будет **автоматически вставлен в поле комментария**

#### Быстрое создание тезиса (`Ctrl+Shift+N`)

Позволяет не прерывая работу на странице быстро сохранять интересные тезисы:

1. Нашли интересный текст в посте, комментарии или статье — **скопируйте его** (`Ctrl+C`)
2. Нажмите `Ctrl+Shift+L`
3. Откроется **форма создания тезиса** с текстом из буфера обмена уже в поле «Вопрос»
4. При необходимости переместите текст в поле «Ответ», допишите недостающее
5. Выберите существующую тему или создайте новую (опция «+ Новая тема»)
6. Нажмите **«Сохранить тезис»** — тезис добавлен, поля очищены для следующего

После сохранения тема автоматически становится активной — следующий сбор промпта (`Ctrl+Shift+P`) будет использовать её.

#### Плавающая панель

Все действия отображаются в **перетаскиваемой панели** в правом верхнем углу страницы. Панель использует Shadow DOM для изоляции стилей от VK. Панель можно перетаскивать за заголовок, закрывать кнопкой ✕.

## Структура проекта

```
commenter/
├── manifest.json                 # Manifest V3
├── options/                      # Основная страница управления
│   ├── options.html              # Полноэкранный интерфейс (4 вкладки)
│   ├── options.css               # Стили, тёмная тема
│   └── options.js                # Логика UI + экспорт/импорт/промпт
├── popup/                        # Popup-окно расширения
│   ├── popup.html                # Кнопка «Полная версия» → openOptionsPage()
│   ├── popup.css
│   └── popup.js
├── content/                      # Контент-скрипты для сайтов
│   └── vk.js                     # VK: извлечение контекста, генерация, тезисы
├── background/
│   └── service-worker.js         # Фоновый скрипт, проксирование API-запросов к LLM
├── lib/
│   ├── storage.js                # CRUD тем и тезисов (chrome.storage.local)
│   └── providers/
│       ├── provider-base.js      # Базовый класс провайдера
│       ├── z-ai.js               # Провайдер Z-AI (GLM-4 Plus/Flash/Long)
│       └── openrouter.js         # Провайдер OpenRouter
├── assets/icons/                 # Иконки расширения (16/48/128px)
├── pack.py                       # Скрипт упаковки в zip
└── README.md
```

## Поддерживаемые модели

### Z-AI

| Модель | Описание |
|--------|----------|
| GLM-4 Plus | Основная модель, лучший баланс качества и скорости |
| GLM-4 | Стандартная модель |
| GLM-4 Flash | Быстрая модель для простых ответов |
| GLM-4 Long | Длинный контекст для объёмных тем |

### OpenRouter

| Модель | Описание |
|--------|----------|
| GPT-4o / GPT-4o Mini | OpenAI |
| Claude Sonnet 4 / Claude 3.5 Haiku | Anthropic |
| Gemini 2.0 Flash | Google |
| DeepSeek Chat | DeepSeek |
| Llama 3.1 70B | Meta |

Любая другая модель OpenRouter доступна через ручной ввод названия.
