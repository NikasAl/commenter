# Commenter

Chrome-расширение для формирования аргументированных ответов на комментарии и посты с помощью LLM.

Идея проста: вы заранее собираете **тезисы** по темам (в формате «Вопрос → Ответ»), а когда нужно ответить на комментарий — выбираете тему, и LLM формирует ответ на основе ваших тезисов.

## Возможности

- **Темы и тезисы** — создавайте неограниченное количество тем, в каждой храните тезисы в формате «Вопрос — Ответ»
- **Генерация ответа** — выберите тему, вставьте текст для ответа, получите ответ с учётом ваших тезисов
- **Мультишаблоны промптов** — создавайте несколько именованных шаблонов системного промпта, переключайтесь между ними из панели VK и вкладки генерации
- **Работа с VK** — извлечение контекста поста и комментариев прямо со страницы VK, генерация ответа и вставка в поле ввода
- **Автовыбор тезисов** — LLM автоматически определяет релевантные тезисы из темы по тексту поста (два режима: полный анализ и по ключевым словам)
- **Карточки для запоминания** — полноэкранный просмотрщик флеш-карточек с переворотом, навигацией, отслеживанием повторений и сортировкой по «давно не повторял»
- **Создание тезисов на лету** — скопировали интересный текст на странице, нажали хоткей — сохранили как тезис в пару кликов
- **Импорт/Экспорт** — импортируйте тезисы из текстового файла (T/Q/A формат) с дедупликацией, экспортируйте обратно
- **LLM-провайдеры** — поддержка **Z-AI**, **OpenRouter** и **локального сервера** (OpenAI-совместимый протокол, например Ollama, vLLM, llama.cpp)
- **Поиск и фильтрация тезисов** — мгновенный текстовый поиск по тезисам в панели VK с подсветкой совпадений
- **Ключевые слова** — LLM извлекает ключевые слова из поста, совпадения подсвечиваются в списке тезисов тегом `<mark>`
- **Управление моделями** — добавляйте и удаляйте модели для каждого провайдера, сбрасывайте к списку по умолчанию
- **Анализ текста** — вставьте статью или обсуждение, LLM автоматически выделит из текста тезисы в формате «Вопрос — Ответ» с привязкой к темам
- **Копирование в один клик** — сгенерированный ответ копируется в буфер обмена мгновенно
- **Повторная генерация** — не устраивает вариант? Нажмите «Ещё вариант»
- **Всё хранится локально** — API-ключи, темы и тезисы сохраняются только в вашем браузере

## Установка

### Из исходников (режим разработчика)

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/NikasAl/commenter.git
   ```
2. Откройте в Chrome `chrome://extensions/`
3. Включите **«Режим разработчика»** (переключатель в правом верхнем углу)
4. Нажмите **«Загрузить распакованное расширение»**
5. Выберите папку `commenter`

### Упаковка в zip

Для ручной установки или загрузки в Chrome Web Store можно собрать архив:

```bash
python3 pack.py
```

Создастся файл `commenter-extension.zip` со всеми необходимыми файлами.

## Как пользоваться

### Вариант 1: Отдельная страница управления

Основной интерфейс расширения открывается на **отдельной вкладке браузера** и не закрывается при потере фокуса. Открыть его можно:

- Кликнув по иконке расширения → **«Полная версия»**
- Через `chrome://extensions/` → Commenter → «Подробности» → «Параметры расширения»

В шапке страницы расположены кнопки **«Карточки»** (открывает просмотрщик флеш-карточек) и выпадающий список вкладок.

На странице 5 вкладок:

#### 1. Генерация

1. Выберите **шаблон промпта** из выпадающего списка
2. Выберите тему из выпадающего списка (отображается количество тезисов)
3. Вставьте текст комментария или поста, на который нужно ответить
4. Нажмите **«Сформировать ответ»**
5. Скопируйте результат или запросите другой вариант

Кнопка **«Копировать промпт»** позволяет скопировать собранный промпт (системный + контекст) для ручного использования в любом чате с LLM.

#### 2. Темы

- **Добавить тему** — создайте тему с тезисами вручную (модальное окно с полным CRUD: добавление, редактирование и удаление отдельных тезисов)
- **Импорт** — вставьте текст в формате T/Q/A для массового добавления тем и тезисов. Дубликаты определяются автоматически и пропускаются. После импорта отображается статистика: сколько создано, сколько пропущено, сколько уже существовало
- **Экспорт** — скачайте все темы и тезисы в текстовый файл (имя файла содержит дату)

Формат импорта/экспорта:
```
T:Название темы
Q:Текст вопроса
A:Текст ответа

Q:Следующий вопрос
A:Следующий ответ

T:Другая тема
Q:...
A:...
```

#### 3. Шаблоны промптов

Система мультишаблонов позволяет создавать несколько именованных шаблонов системного промпта и быстро переключаться между ними. Поддерживаются шаблонные переменные:

- `{{topic}}` — подставляется название выбранной темы
- `{{theses}}` — подставляются все тезисы темы в формате «[Тезис N] Вопрос / Ответ»

Возможности редактора:
- Список всех шаблонов с индикацией активного и превью длины
- Создание, редактирование, удаление шаблонов
- Активация шаблона одним кликом (для использования при генерации)
- **Живой предпросмотр** с подстановкой тестовых данных
- Кнопка сброса к значению по умолчанию
- Первый созданный шаблон автоматически становится активным

#### 4. Анализ текста

Вкладка для автоматического извлечения тезисов из произвольного текста — статей, постов, обсуждений, новостных материалов и т.д. LLM анализирует текст и выделяет ключевые тезисы в формате «Вопрос — Ответ», готовые для сохранения в базу.

Поддерживается два режима:

- **С выбранной темой** — выберите существующую тему из списка, вставьте текст, нажмите **«Анализировать текст»**. LLM выделит тезисы по заданной теме. После анализа можно отметить нужные тезисы чекбоксами и добавить их в базу одной кнопкой.

- **Авто (определение тем)** — оставьте выбор темы в положении «Авто». LLM самостоятельно определит темы, затронутые в тексте, и распределит тезисы по ним. Затем запустится **шаг группировки**: LLM попытается привязать найденные темы к уже существующим в вашей базе. Вы сможете:
  - Увидеть, какие темы привязаны к существующим, а какие новые
  - Сменить привязку вручную через выпадающий список
  - Повторить группировку, если результат не устроил
  - Сохранить выбранные тезисы в базу (новые темы создадутся автоматически)

#### 5. Настройки

- Выбор провайдера (**Z-AI**, **Локальный сервер** или **OpenRouter**)
- **Локальный сервер** — поле для ввода адреса (URL) развёрнутого LLM-сервера (по умолчанию `http://turbo:8080`), API-ключ не обязателен
- Вставка API-ключа (хранится локально)
- Выбор модели из выпадающего списка для каждого провайдера
- **Пользовательская модель** — ручной ввод названия модели
- **Управление моделями** — модальное окно для добавления/удаления моделей каждого провайдера и сброса к списку по умолчанию
- **Автовыбор тезисов** — переключатель для автоматического определения релевантных тезисов при генерации
- **Режим выбора тезисов** — выбор алгоритма (полный анализ LLM / по ключевым словам)

### Вариант 2: Карточки (флеш-карточки)

Просмотрщик открывается кнопкой **«Карточки»** в шапке страницы настроек. Предназначен для запоминания тезисов с помощью интервального повторения.

Возможности:
- **Фильтр по теме** — отображать карточки всех тем или выбрать конкретную
- **Флип-карточки** — CSS 3D-анимация переворота: лицевая сторона (вопрос) ↔ обратная сторона (ответ)
- **Отслеживание повторений** — при каждом просмотре карточки записывается метка времени; карточки сортируются по принципу «давно не повторял — первым»
- **Навигация** — кнопки назад/вперёд, клавиатурные стрелки, точечная навигация (с группировкой при >30 карточках), полоса прогресса
- **Клавиатурные сокращения** — стрелки (навигация), Пробел/Enter (переворот), E (редактирование), Delete (удаление), Escape (закрыть)
- **Тач/свайп** — поддержка горизонтального свайпа для мобильных устройств, тап для переворота
- **Редактирование и удаление** — модальные окна для изменения тезиса прямо из карточки и удаления с подтверждением
- **Относительное время** — отображение «давно просмотрен» (секунды / минуты / часы / дни / недели)
- Адаптивная вёрстка для мобильных устройств

### Вариант 3: Интеграция с VK (хоткеи на странице)

При открытии страницы **vk.com** расширение автоматически активирует контент-скрипт, который добавляет три горячие клавиши. Для работы нужен настроенный API-ключ или адрес локального сервера (вкладка «Настройки»).

#### Хоткеи

| Горячая клавиша | Действие |
|---|---|
| `Ctrl+Shift+P` | Извлечь контекст поста + комментарии, собрать промпт |
| `Ctrl+Shift+G` | Отправить промпт в LLM, вставить результат в поле комментария |
| `Ctrl+Shift+L` | Открыть форму создания нового тезиса (из буфера обмена) |

#### Сбор промпта (`Ctrl+Shift+P`)

1. На странице VK поставьте фокус в **поле комментария** (кликните в поле ввода под постом)
2. Нажмите `Ctrl+Shift+P`
3. Появится **плавающая панель** с собранным контекстом:
   - Автор поста и текст поста
   - Список комментариев (автор + текст)
   - Контекст ответа (если отвечаете на конкретный комментарий)
   - Системный промпт с тезисами выбранной темы
4. В панели есть **селектор темы** — выберите нужную тему, и промпт мгновенно пересоберётся с её тезисами
5. Промпт автоматически копируется в буфер обмена

#### Генерация и вставка (`Ctrl+Shift+G`)

1. Убедитесь, что промпт собран (`Ctrl+Shift+P`) и тема выбрана
2. Фокус должен быть в поле комментария VK
3. Нажмите `Ctrl+Shift+G`
4. Панель покажет статус «Генерация...», затем результат LLM будет **автоматически вставлен в поле комментария**

#### Быстрое создание тезиса (`Ctrl+Shift+L`)

Позволяет не прерывая работу на странице быстро сохранять интересные тезисы:

1. Нашли интересный текст в посте, комментарии или статье — **скопируйте его** (`Ctrl+C`)
2. Нажмите `Ctrl+Shift+L`
3. Откроется **форма создания тезиса** с текстом из буфера обмена уже в поле «Вопрос»
4. При необходимости переместите текст в поле «Ответ», допишите недостающее
5. Выберите существующую тему или создайте новую (опция «+ Новая тема»)
6. Нажмите **«Сохранить тезис»** — тезис добавлен, поля очищены для следующего

После сохранения тема автоматически становится активной — следующий сбор промпта (`Ctrl+Shift+P`) будет использовать её.

#### Плавающая панель

Все действия отображаются в **перетаскиваемой панели** в правом верхнем углу страницы. Панель использует Shadow DOM для изоляции стилей от VK. Панель можно перетаскивать за заголовок, закрывать кнопкой ✕.

Элементы панели:
- **Селектор модели** — выпадающий список с группировкой по провайдерам (Z-AI, Локальный, OpenRouter), цветной бейдж провайдера, поддержка пользовательских моделей. Позволяет переключать модель прямо из VK, не открывая настройки
- **Селектор шаблона** — переключение шаблона промпта без перезагрузки
- **Селектор темы** — выбор темы с отображением количества тезисов, мгновенная пересборка промпта
- **Список тезисов** — чекбоксы для ручного выбора/отмены, кнопки «Все» / «Ни одного», счётчик выбранных
- **Поиск по тезисам** — текстовое поле для мгновенной фильтрации списка тезисов с отображением количества совпадений
- **Подсветка ключевых слов** — при режиме «ключевые слова» совпадения выделяются тегом `<mark>` прямо в тексте тезисов
- **Системный промпт** — сворачиваемый блок `<details>` для просмотра текущего системного промпта
- **Редактируемый контекст** — текстовое поле с текстом пользовательского сообщения (извлечённым из поста), можно отредактировать вручную, кнопка сброса к оригиналу
- **Кнопка копирования** — копирует полный собранный промпт в буфер обмена с визуальным подтверждением
- **Подсказка хоткеев** — панель с перечислением доступных горячих клавиш

#### Автовыбор тезисов

Если в настройках включён переключатель «Автовыбор тезисов», при сборе промпта (`Ctrl+Shift+P`) LLM автоматически определит, какие тезисы из выбранной темы релевантны тексту поста. Доступны два алгоритма:

- **Полный анализ** — LLM получает все тезисы темы и полный текст поста, возвращает номера релевантных тезисов. Метод точный, но более медленный и дорогой (двойной вызов LLM)

- **Ключевые слова** — LLM извлекает ключевые слова из поста, затем выполняется локальный поиск совпадений по тексту тезисов. Метод быстрый (один вызов LLM), совпадения подсвечиваются в панели тегом `<mark>`. Для ручной корректировки можно переключиться на ручной режим и отметить/снять нужные тезисы

```
│   ├── options.css               # Стили, тёмная тема
│   └── options.js                # Логика UI + экспорт/импорт/шаблоны/настройки
├── viewer/                       # Просмотрщик флеш-карточек
│   ├── viewer.html               # Полноэкранный интерфейс карточек
│   ├── viewer.css                # Стили, 3D-флип анимация, адаптивная вёрстка
│   └── viewer.js                 # Навигация, свайп, редактирование, отслеживание
├── popup/                        # Popup-окно расширения

│   ├── popup.css
│   └── popup.js
├── content/                      # Контент-скрипты для сайтов
│   └── vk.js                     # VK: панель, извлечение контекста, генерация, тезисы
├── background/
│   └── service-worker.js         # Фоновый скрипт, маршрутизация запросов к LLM
├── lib/
│   ├── storage.js                # CRUD тем/тезисов/шаблонов, миграция настроек
│   └── providers/
│       ├── provider-base.js      # Базовый класс провайдера
│       ├── z-ai.js               # Провайдер Z-AI (GLM-4.7, GLM-5.1)
│       ├── openrouter.js         # Провайдер OpenRouter (12 моделей)

└── README.md
```

| Модель | Описание |
|--------|----------|
| Gemma 4 26B | Модель по умолчанию |
